# 03. 「8/140 vs 1/20 ＝ 8/7」の謎の構造と仮説群

## 1. 現象の数理的要約

実測データ（クリティカル・スキル発動を完全排除した純粋白ノーツ）の検証により、以下の矛盾する2つの事実が確定した：

1. **T5（デイリー）および S3（EXタワー ⅢX）**:
   - 係数 $\lambda = 8/140 \approx 0.057143$（約 5.714%）で実測値と乱数平均 1.000（±5%以内）で完全一致する。
   - もし 1/20（5.000%）にすると、約 -12.5%〜-14% も過小になり、全滅する。
2. **S4（EXタワー Liznoir）**:
   - 係数 $\lambda = 1/20 = 0.050000$（5.000%）で実測値と平均 0.9962（誤差 -0.38%）で完全一致する。
   - もし 8/140（5.714%）にすると、約 +13.85% も過大になり、全滅する。

両者の比率は極めてシンプルかつ正確に整数比である：
$$\frac{8/140}{1/20} = \frac{8/140}{7/140} = \frac{8}{7} \approx 1.142857 \quad (+14.286\%)$$

## 2. なぜ「ノーツ数分割説（$\lambda = 8/N_{\text{beat}}$）」は成り立たないか？

Fable 5.1 が提唱した「曲のノーツ数 $N_{\text{beat}}$ で割っている」という仮説は、以下の実測事実によって完全に否定される：

- **S3 と S4 のノーツ数はほぼ同一（148 vs 149）**:
  - S3 (STAGE045): 通常ビート **148**（総ノーツ169、A19、SP2）
  - S4 (STAGE054): 通常ビート **149**（総ノーツ166、A14、SP3）
  - もしノーツ数で等分されているなら、S3 と S4 の係数は同じでなければならない。
  - しかし実測では、S3 は $8/140$ で合い、S4 は $1/20$（8/140の 7/8）で合う。
  - したがって、ノーツ数 $N_{\text{beat}}$ はこの 8/7 の差の原因ではない。

## 4. やる気士 docs とマスターデータの数理的整合性

やる気士 docs の基本比率：
- センター属性: 3.00%
- 準属性: 1.25%
- 劣勢属性: 0.75%
- 合計: 5.00%（$= 1/20$）

マスターデータ（`Quest.json`）の `beatWeightsPermil`：
- センター属性: 600‰
- 準属性: 250‰
- 劣勢属性: 150‰
- 合計: 1000‰

マスタの比率（600 : 250 : 150）に **1/20（5.0%）** を掛けると：
- $600‰ \times 1/20 = 30‰ = 3.00\%$
- $250‰ \times 1/20 = 12.5‰ = 1.25\%$
- $150‰ \times 1/20 = 7.5‰ = 0.75\%$
完全に一致する。

すなわち、**やる気士 docs の定義式は「$basicSum \times 1/20$」そのもの**である。
S4 はこのやる気士 docs の定義に 100% 厳密に合致している。

問題は、**「なぜ T5 と S3 では、これがちょうど 8/7 倍（$8/140 \approx 5.714\%$）にスケールアップしていたのか？」** である。
