# Phase 16 Action14 / タスク A4: 可読セル比 `sim(可読)/Σpop` を検査3 としてゲート化（検査2 の分母・閾値は不変）

## 1. なぜ必要か

検査2 は「pop が読めないセル」だけを見るため、**可読セルの配分がずれている**ケースを検出できない:

| 例 | 実測レーン合計 | sim レーン合計 | 検査2（下側） | 可読セル比 |
|---|---:|---:|---|---:|
| S2 L3 | 49,841,012 | 48,173,385 | 0.22× FAIL(下) | **0.970** |
| S1 L2 | 6,108,813 | 6,472,820 | 1.14× WARN | **1.103** |
| S3 L5 | 9,560,444 | — | 1.30× WARN | **1.075** |

実測 `Σpop` は K/M 表記の切り捨てで**高々 +0.6%（K 単位）**しか過小評価しないので、比が
1 から ±7% 以上離れていれば測定誤差では説明できない。

## 2. 閾値（15 レーンの実測分布から決定）

15 レーン × photo-gate off/on（= 30 行）の分布:

```
0.953, 0.963, 0.970, 0.970, 0.974, 0.981, 0.990, 0.997,
1.021, 1.028, 1.050, 1.075, 1.075, 1.078, 1.103        （S1/S2/S3 の 15 レーン）
min 0.953 / max 1.103 / 中央値 ≈ 0.997
```

→ **`比 ≥ 1.20 = FAIL ／ 1.07〜1.20 = WARN ／ 0.93〜1.07 = OK ／ 0.80〜0.93 = WARN(下) ／ ≤ 0.80 = FAIL(下)`**

- FAIL 帯は観測最大（1.103）から **+8.8%**、観測最小（0.953）から **−16%** の余裕を取った
  （＝今日 FAIL するレーンは無い。回帰検出用の帯）。
- WARN 帯（±7%）は今日 4 レーンが該当し、**可読セル配分のずれが大きい順に並ぶ**（S1 L2 1.103 /
  S3 L1 1.075 / S1 L2 1.078 など）。閾値は母集団（15 レーン）より**狭く**取ってあるので、
  新サンプルを足したときに較正が要る場合は「分布を出し直してから」動かすこと。
- 上側 FAIL は検査1・2 と同じく exit 1 に効く。下側 FAIL は `--low-gate` の扱いに従う
  （既定 fail / `warn` / `off`）。**検査2 の分母・閾値は 1 も変えていない。**

## 3. 実装

- 各行に `simRead` / `popSumLane` / `readRatio` を持たせ、`basis=merged` の行（Σpop 統合口径）から
  **photo-gate off/on の最悪値**（1 からの距離が最大）を 1 レーン 1 行に畳んで判定する。
- 出力: `########## 検査3: 可読セル比 ##########` 節（全 15 行の内訳つき）＋まとめ行。
- スタミナ系列の検査は **検査4** に改番（`--ledger` 時のみ・S1 L1 必須の規約は不変）。

実行結果（2026-10-07・`npm run audit:hidden -- --low-gate=warn`）:

```
  検査3（可読セル比・A14/A4）: FAIL 0 件（上 0 / 下 0） / WARN 4 件（最悪 1.103× = S1 L2）
  上側ゲート: PASS
  下側ゲート: WARN 止まり（1 件・exit に効かない）   ← 検査2 の S2 L3 0.22×
  ゲート結果: PASS
```

- `npm run audit:hidden -- --low-gate=warn` → **exit 0**
- `npm run audit:hidden`（既定）→ **exit 1**（従来どおり検査2 下側の S2 L3 0.22× のみが理由）

## 4. 残る FAIL（S2 L3 0.22×）を消せない理由【数値】

検査3 は S2 L3 を 0.970×（OK 帯）と判定する。つまり **sim は可読セルの 97.0% を説明できており、
不足 1,667,627 の大半は「可読セルの中での不足」**（A2 の A/SP セル台帳: b10:3 −3.8%、b41:3 −7.6%、
b90:3 SP −2.5%）である。これは隠れセル（2 セル・sim 43,738）の話ではないため、**閾値・分母を動かしても
0.22× は消えない**（分子を対称化して 0.19 → 0.22 に改善済み）。消すにはレーン別オフセット
（A3 の φ = L3 1.074・A/SP セルでは 0.92〜1.03）の解明が必要で、**A14 の守備範囲外**として数値を残す。
