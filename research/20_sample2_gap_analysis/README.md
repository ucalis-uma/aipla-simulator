## 2. 確定・修正した仕様（出典: S2 issues.md・実測照合）

1. **誰かが低下効果状態の時（`tg-someone_status_group-weekness` → `someone_down_group`）**:
   実測では L1 の「憧れていた青春」が**全編不発**（低下効果スキルなし）。旧実装は無条件扱いで
   b2/b60/b120 に余分発動し、L1 の「本当は起きてた」の CT 予算を b1 で奪っていた
   （実測の発動間隔 b1→b55→b110→b165 = CT55 前半発動の CT-1/CT モデルどおり）。
   → importer で condition 化・engine に `someone_down_group` 条件追加（vocal/dance/visual_down の OR）。
   【Confirmed: S2 実測・発動ログ 44 件と発動間隔 3 系列】

2. **効果行単位の triggerId**（importer）: 似た者親子のメッセージ等は
   「score_get 行は無条件・バフ行のみ `tg-position_attribute_visual`」の混合構成で、
   スキル単位 triggerId には入らない。`skillDetails[].triggerId` を効果行ごとに写像する。

3. **CLI の audience 上書き修正**: 入力 JSON に `audience` が明示されている場合は
   会場キャパ cap/5 による上書きを**しない**（S2 の fan.png 実測 13,206 人が 14,000 に
   上書きされていた。S1 の 71,000 問題は「誤値だった」問題であり、正しい実測値の尊重は別問題）。
   【Confirmed: S2 fan.png 全 5 レーン × 検算 — fan.png のスコアボーナス% は
   個人来場ファン数 × fan_bonus テーブルと 1 の位まで一致（L1 53.9%↔11,996 人 等）】

4. **fan.png の検算（新知見）**: 実測「スコアボーナス%」= `fanBonusPermilFromCount(個人来場)`
   と完全一致（L3 57.4% ↔ 13,741 人）。**fan_bonus テーブル（FAN_BONUS_SEGMENTS）の
   実装が実機と一致する独立検証**になった。引力式（集目配分）込みの L3 予測 1610‰ は
   実測 1574‰ と Δ36‰ — 集目 6 段の配分分が過大（要・次サンプル検証）。

## 3. 残差の定量（crit フラグ再現ラン）

- **A/SP クリティカル 4+1 イベントの必要 critF**: b10 ×1.040 / b142 ×1.003 / b126(L1) ×1.018 は
  ±5% 乱数帯で両立。b41 ×0.905 / b100 ×0.886 は帯の外（旧実装が ccu を過大に保持）。
  → **【2026-09-02 第二段階で解決】** ①超化は増強型（同種最長インスタンスへ +5・基底なしで不発）
  ②A/SP も効果行ごとに独立条件評価（怜 A2 の ccu 6 段行はダンスレーンでは不発）
  の 2 修正で b41 critF=2504（ccu13）/b100=1854（ccu0）/b142=2254（ccu8）がユーザー式と完全一致。
  旧 ccu=19 は「怜 A2 の条件行が無条件で発動していた」誤りが主因。
- **b90 SP**: sim 43.3M vs 実測 29.5M。構造は正しい（score_get 行 + 13% 割合行の 2 行）。
  実測を ±5% で満たす組: スケーリング段数 = visual_up 実効段数（22-25 段）+ critF ≈ 2350-2500 +
  割合 basis = L3 累積（neutral 約 11.5M）。sim 過大の主因は **critF 過大（ccu 13-25 → 必要 ≈10）**
  と **割合 basis が crit 込み累積で膨張する循環**。
- **ビート crit（111 件の L3 Y ポップ等）**: 単一 crit ビートの必要 critF は ccu 依存の傾きが
  ほぼ無い（1500-1850 帯で平壊）— ビートノートの crit に ccu が乗っていない可能性。
  → **【第二段階で撤回】** 旧 ccu 系列が誤っていたため傾きが出ていなかっただけ。
  修正後の ccu 系列で L3 合計 ×0.976（±5% 内）となり、ビート crit も A/SP と同一式
  （critF = 1500 + 50×ccu + extras）で両立。
