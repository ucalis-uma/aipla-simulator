## 1. ライブボーナスの発動順序と処理仕様

### ■ ビート内処理フロー
1. **最優先発動**: 全てのアイドルPスキル（メンタル降順）やフォトよりも**先頭（最優先）**で判定・発動する。
2. **前半発動（スコア精算前）**:
   - 「ライブ開始時」「誰かのスキル発動前」「ビート時（無条件）」など。
   - スコア精算前にバフが乗るため、**そのビートのスコアに乗る**。
   - 同ビート内の効果時間減算処理により、実効持続ビート数は 表記ビート数 - 1。
3. **後半発動（スコア精算後）**:
   - 「誰かが○○状態の時」「○○コンボ以上時」「CT回復直後」など。
   - スコア精算およびCT・バフ時間の減算処理が終わった後、**後半Pスキル群の中で最も最初に発動**。
   - 条件未成立時は発動が保留され、成立ビートの後半で発動。実効持続ビート数は 表記ビート数そのまま。
4. **CT短縮ライボ**:
   - ライボによってCT短縮されたPスキルは、最終的にライボの発動タイミングに収束（同期）する。

### ■ データ連携パイプライン
Quest.json (liveBonusGroupId) -> LiveBonusGroup.json -> LiveBonus.json -> LiveAbility.json -> Skill.json (sk-live-lba-passive_skill-*)

## 2. 集目（focus）の正確なファンボーナス加算テーブル

集目の副効果（ファンボーナス固定加算）は、**「1〜5段は +0.7%/段、6〜10段は +0.3%/段」**（最大+5.0%）である。

`	s
// src/timeline/constants.ts
// インデックス 0 = 1段階 (+7‰), インデックス 9 = 10段階 (+50‰)
export const FOCUS_FAN_BONUS_PERMIL: readonly number[] = [
  7,   // 1段: +0.7%
  14,  // 2段: +1.4%
  21,  // 3段: +2.1%
  28,  // 4段: +2.8%
  35,  // 5段: +3.5%
  38,  // 6段: +3.8%
  41,  // 7段: +4.1%
  44,  // 8段: +4.4%
  47,  // 9段: +4.7%
  50,  // 10段: +5.0% (上限)
];
`

## 3. 「超化」スキルの統一仕様

「スコア上昇超化」「クリティカル係数上昇超化」「ボーカル/ダンス/ビジュアル上昇超化」など。

1. **効果量**: 元のバフの通常上限（20段等）とは独立に、**元のバフの「+5段階分（固定値）」**として加算される。
2. **段階数のダミー性**: スキル表記上の段階数（「5段階」「10段階」等）は単なる仕様上のダミー値で、**効果は一律 +5段階相当**。
   - **スコア超化**: スコアボーナス **+12.5%**（125‰）
   - **係数超化**: クリティカルボーナス **+25.0%**（250‰）
   - **ステータス超化（Vo/Da/Vi超化）**: ステータス **+25.0%**（250‰）

> **【2026-09-02 実装確定（Phase 11・S2 ユーザー確定）】**: 上記の「+5段階分」は
> **独立インスタンスではなく増強型**として実装 — 同種バフの残りビート最大インスタンスへ
> +5 段加算し、そのインスタンスの上限も +5 拡張する（`capExtend` に加算量を記録）。
> **基底インスタンスが存在しない場合は不発**（表記段階数はダミー）。根拠: S2 実測で
> 千紗P2（ccu8 段[45b]）+ 千紗A1 超化（+5）の組み合わせが ccu 8→13 を再現し、
> 基底消滅後の b100 で ccu=0（超化単独では発動しない）が critF 1 の位まで一致
> （research/13 §超化の方式・research/20 CONCLUSION 第二段階節参照）。

## 4. クリティカル発生率と動的判定

1. **固定値上限**: キャラクターのクリティカル値による素のクリティカル率は **最大50%で頭打ち**。
2. **バフ加算**: クリティカル率上昇バフは **1段階あたり +5%（加算）**。
3. **確定ライン**: **20段階（+100%）で固定値に関係なく確定クリティカル（100%）**。
4. **計算式**:
   effectiveCritRate = min(0.50, baseCritRate) + (critical_rate_up段数 * 0.05)
   （effectiveCritRate >= 1.0 の場合は抽選なしで確定クリティカル）

## 5. メンタル要求値とテンション副効果

1. **基礎成功率**: ステージの mentalThreshold（メンタル要求値）を満たしていれば成功率100%。不足時は100%未満（メンタル割れ）。
2. **テンション上昇の副効果**: テンション1段階あたり **成功率 -1.5%** の低下ペナルティ（10段階で -15%）。

## 3. 段階数参照スコア（type36・「段階数が多い程効果上昇」）の Peing アンカー（2026-09-01 追記）

type36 の段階あたり係数はマスタに存在しない（ゲーム内部定数・research/07 §280）。
エンジン関数形は `SkillPower × (1000 + perStagePermil × 参照段数) / 1000`（線形乗算・T5 較正済み）。
**Peing の実数値回答から、未較正スキルの係数を逆算できる**:
