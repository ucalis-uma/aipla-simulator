# プロンプト：実測バフ不一致の修正（LLM画像精査に基づくS3/T5/S1健全化）

## 1. 目的と背景
前セッションまでのバフ突合において表面化していた不一致のうち、LLM自身の直接画像分析により以下の事実が確定した：
1. **S3 Lane 4 b25〜b28 (`BUFF_STAGE_MISMATCH` 4件)**:
   - 実機スクショ（`beat_025.PNG` / `beat_025_2.PNG`）には「3段階 ビジュアルブースト」と「5段階 ボーカル上昇」のみが写っており、「5段階 ボーカルブースト」は存在しない。
   - スクロール統合パッチ（`patch_plan_s3.json`）が類似度 0.876 で誤認追加していたデータ汚染（OCR誤認）である。これを削除することで S3 の `BUFF_STAGE_MISMATCH` は 4件 → 0件に完全消滅する。
2. **T5 Lane 3 b87〜b99 (`BUFF_STAGE_MISMATCH` 10件)**:
   - 実機スクショ（`IMG_0860.PNG` 等）に明確に「20段階 ボーカルブースト」が表示されているのに対し、シミュレータは 17段で 3段不足している。シミュレータ側のブースト合算漏れを特定・修正する。
3. **S1 Lane 1 b136〜b143 (`DECAY_TIMING_LAG` 14件中8件)**:
   - 実機スクショ（`beat_136.PNG` 等）に「ボーカル上昇 3段」は表示されておらず、シミュレータ側が莉央 P3（全員延長）により b136 以降も不要に延長し続けている。延長判定の境界条件を精査・是正する。
4. **S3 開幕ビート (`AMPLIFY_OR_OVERLAP` 6件)**:
   - b1 開始時および b2, b61 のフォトスキル・パッシブ発動順序と重複合算の適正化。

## 2. 実施手順
1. **S3 実測パッチの是正 (`research/26_data_integrity/apply_patch_s3.py`)**:
   - `patch_plan_s3.json` から誤認追加された `ボーカルブースト 5段`（b24〜b28 Lane 4）を除去。
   - `apply_patch_s3.py` を実行して `measured_data_s3_v3.json` を再生成。
   - `run_audit_s3_v3.py` を実行し、`BUFF_STAGE_MISMATCH` が 0件になることを確認。
2. **T5 Lane 3 ボーカルブースト 3段不足の解明と修正**:
   - b87 前後の各スキル発動・フォト効果のブースト付与元をトレースし、シミュレータ側で取りこぼされている 3段（どのスキルの効果か）を特定・修正。
3. **S1 Lane 1 ボーカル上昇の延長過剰の解明と修正**:
   - b136 で延長される直前の `remainingBeats` と、実機の消滅タイミング（b135以前）を比較し、延長対象判定を適正化。
4. **S3 開幕ビート合算の適正化**:
   - b1 の focus / score_up / visual_boost の発動順序と上限クランプを実機画像通りに適正化。

## 3. 完了条件
- S3 の `BUFF_STAGE_MISMATCH` が 0件 になること。
- T5 の `BUFF_STAGE_MISMATCH` が 0件 になること。
