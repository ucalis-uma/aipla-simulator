# Phase 16 アクション1: 通常ビートスコア計算式の同定および S3 乖離要因分解

作成: 2026-09-29 ／ 対象: 通常ビートスコア計算モデル（$\lambda$・フォト重複）の検証と S3 スコア乖離分析
関連: `research/23_beat_score_analysis/` / `research/21_sample3_gap_analysis/` / `src/sim/build.ts`

---

## 1. 背景と目的

Phase 15 までに、全4サンプル（S1, S2, S3, T5）において **バフの一致率（adjusted）が 100.0%（真の不一致 residual 0 件）** を達成した。
バフ状態遷移の未解明なズレが解消されたため、Phase 16 では **「スコア計算そのもののモデル乖離（スコア側ギャップ）」** の解明・是正に着手する。

本アクション1の目的は以下の2点である：
1. **通常ビート計算式の同定（やる気士 docs 式 vs 現行エンジン式）**:
   - すべてのフォト効果（A/SP/P/クリスコ）が自然な `sum`（加算）型であるのに対し、現行エンジンでは `beat_score` だけが例外的に `max`（最大値のみ）とされている。
   - 「通常ステージ（ハイスコア/デイリー）では、やる気士 docs 式（$\lambda = 1/20$ かつ フォト `sum`）ですべてのビートが乱数範囲内に収まるのではないか」という仮説を検証する。
2. **S3（EXタワー）確定値乖離（confirmed −8.24%）の要因分解**:
   - S3 はリプレイモードでは誤差 −1.17%（158/159 ビートが乱数内）と極めて高精度であるにもかかわらず、乱数中立の確定値（confirmed）では実測基準（72,176,945）に対しシミュレータ（66,378,887）が約 −8.24% 低く出る。
   - この 8% の差が「通常白ノーツ」「クリティカル倍率」「スキルノーツ（A/フォト）」のどこに起因しているかを完全に切り分ける。

---

## 2. 合格判定基準（最重要規律）

* **判定基準は「全ビート個別に比率 $\frac{\text{sim}}{\text{meas}} \in [0.9500, 1.0500]$（$\pm 5.0\%$）内に収束すること」**。
* **平均値での判定は禁止**: たとえ平均比率が 1.000（誤差 0%）であっても、1ビートでも乱数範囲 $[0.9500, 1.0500]$ をはみ出したモデルは即座に不合格とする。
* 正しい計算式であれば、乱数に従って全ビートが例外なく $[0.9500, 1.0500]$ 内に収まり、合算スコアの誤差も相殺により $\pm 1\%$ 未満に収束する。

## 4. 分析の進め方とタスク

### Step 1: 分析ツールの作成（`tools/analyze_beat_score_models.ts`）
TypeScript で分析スクリプトを作成する（既存の `src/` コードは恒久変更せず、シミュレータ出力を利用してメモリ上で各モデルの計算値を算出・突合する）。

* **入力データ**:
  * **S3**: `research/21_sample3_gap_analysis/sim_trace_full.json` ＋ `research/26_data_integrity/measured_data_s3_v3.json`
  * **T5**: `research/25_buff_audit/t5_sim_trace_full.json` ＋ `tests/golden/fixtures/t5_measured.json`
  * （必要に応じて S2: `research/20_sample2_gap_analysis/sim_trace_full.json` ＋ `research/26_data_integrity/measured_data_s2_v3.json`）
* **分類ロジック**:
  各ビートを以下の3グループに明確に分離する：
  1. **純粋白ノーツビート**: 全5レーンともクリティカルなし（黄色popなし）、かつスキル（A/SP/フォト）発動なし。
     - 5レーン合算スコア vs Model A〜D の4モデル計算値
     - レーン別スコアポップ（記録があるセル）vs 各モデルのレーン計算値
  2. **スキルビート**: Aスキル、SPスキル、フォトスキル発動ビート。
     - 実測スコア vs sim スコア（比率）
  3. **クリティカル発生ビート**: 1レーン以上でクリティカルが発生したビート。
     - 実測スコア vs sim スコア（クリティカル倍率の整合性確認）

### Step 2: S3 確定値乖離（confirmed −8.24%）の要因分解
* S3 の確定値（乱数中立）において、実測基準値（72,176,945）と sim（66,378,887）の差分 **約 580万点（−8.24%）** の内訳を算出する：
  * 通常ビート（148ビート分）の差分合計
  * Aスキル（19ビート分）の差分合計
  * SPスキル（2ビート分）の差分合計
  * フォトスキル（発動ビート分）の差分合計
* 「通常ビートの差分」が全体の何％を占めているかを明示する。

### Step 3: レポート作成（`research/23_beat_score_analysis/phase16_action1_report.md`）
* Model A〜D の各モデルにおける「全ビート合格率（合格ビート数 / 全ビート数）」の一覧表。
* S3 および T5 でのモデル適合度比較（ハイスコア vs EXタワーで式が違うのか、docs式が両者で成立するのかの判定）。
* S3 confirmed 乖離要因の分解サマリ。
